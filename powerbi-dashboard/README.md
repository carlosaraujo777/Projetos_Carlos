📊 Dashboard de E-commerce — Análise de Vendas
Dashboard em Power BI com análise de vendas de um e-commerce, usando dados públicos do Kaggle .

🎯 Objetivo
Analisar vendas por categoria, região, método de pagamento e evolução mensal, com o objetivo de simulação, DAX e visualização de dados no Power BI.

🛠 Ferramentas
Power BI
Power Query
DAX
📈 KPIs
Total de Vendas: R$ 182 milhões
Ingresso Médio: R$ 92 milhões
Quantidade de Pedidos: 2 Mil
Média de Dias para Entrega: 6,13
💡 Principais Insights
Eletrônicos é a categoria que mais vende (R$ 63 Mi)
Regiões Sul, Leste e Oeste ficam quase empatadas (~25% cada)
Cartão de crédito é o método de pagamento mais usado (897 pedidos)
