# 📊 Dashboard de Vendas — E-commerce

Dashboard em Power BI analisando vendas de um e-commerce, com foco em modelagem de dados, medidas DAX e storytelling visual.

## 🎯 Objetivo
Praticar o fluxo completo de BI: ingestão → modelagem → DAX → visualização, respondendo perguntas de negócio sobre vendas, regiões e formas de pagamento.

## 🛠 Stack
- Power BI Desktop
- Power Query (ETL)
- DAX (medidas e colunas calculadas)

## 📈 KPIs
| Métrica | Valor |
|---------|-------|
| Total de Vendas | R$ 182 Mi |
| Ticket Médio | R$ 92 Mil |
| Pedidos | 2 Mil |
| Média de Entrega | 6,13 dias |

## 💡 Insights
- **Eletrônicos** lidera em faturamento (R$ 63 Mi)
- **Sul, Leste e Oeste** praticamente empatadas (~25% cada)
- **Cartão de crédito** é o meio de pagamento dominante (897 pedidos)
- **Agosto** concentra o pico de vendas
